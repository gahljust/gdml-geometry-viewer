Calculation & selections

ROOT fits all 224 main tiles and 28 ShowerMax virtual planes. Main PE: forward e±, kinetic energy > 1.1 MeV; angle capped at 4°. ShowerMax: forward supported particles. Reference asymmetries use the historical Ring 5 open definition. Display cuts do not change this fit.

Inputs require all three interactions, compatible run settings and geometry, independent seeds, recorded detector entries and event rate normalization. Additional generators add one fit component each. Experimental σ uses the exposure above; MC σ propagates the simulated H uncertainty.
